# Flux Dev Environment

This directory contains the desired state for the `dev` AKS cluster, managed by Flux.

## Structure

```
clusters/dev/
├── flux-system/       # Flux bootstrap manifests (auto-generated by flux bootstrap)
├── apps/              # Application deployments (namespace, HelmRelease, source)
│   ├── namespace.yaml
│   ├── source-gitrepository.yaml
│   ├── helmrelease.yaml
│   └── kustomization.yaml
└── policies/          # Security policies (NetworkPolicy)
    ├── network-policy.yaml
    └── kustomization.yaml
```

## How It Works

Flux watches this directory. Any change committed here is automatically reconciled to the cluster. This is the GitOps source of truth for what runs on AKS.

_Contents to be created in Phase 6._

## Source Model

Because the Helm chart lives inside this same repository under `charts/devsecops-api/`, v1 should use Flux `GitRepository` + `HelmRelease`. Use `HelmRepository` only if the chart is later published to a separate Helm/OCI registry.
